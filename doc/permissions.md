# Rights

| Right | What it allows |
|---|---|
| `ezodf/import` | Import documents, the pages of one's own imports; the old single-document import |
| `ezodf/export` | Export documents (an item one may read, a folder one may read) |
| `ezodf/converter` | The Document converter page (install, server, limits, remote server, cleanup) and the imports of every user |

Importing also needs the right to create items in the target folder; exporting, the right to read the items.
Set them in **Users > Roles**.
